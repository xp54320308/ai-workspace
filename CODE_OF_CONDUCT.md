# Code of Conduct

AI Workspace follows the Contributor Covenant Code of Conduct, version 2.1.

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while still being precise about problems.
- Give actionable feedback.
- Respect privacy and do not share sensitive documents, keys, or personal data.

## Unacceptable behavior

- Harassment, threats, insults, or personal attacks.
- Publishing private information without explicit permission.
- Repeated off-topic disruption.
- Sharing malicious code, credentials, or exploit instructions outside a responsible security report.

## Enforcement

Project maintainers may remove comments, close issues, reject pull requests, or block contributors whose behavior is inconsistent with this code of conduct.

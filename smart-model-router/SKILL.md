# Smart Model Router — 智能模型路由

## 核心理念

**用最合适的模型，而不是最贵的。**

## 任务类型路由表

### 1. 简单任务（快省）

**特征：**
- 简单问答
- 翻译
- 格式转换
- 文件查找
- 确认/确认类问题

**推荐模型：**
```
首选: ollama/qwen2.5:7b
备选: ollama/qwen2.5:14b
```

**触发词：**
```
"是什么"、"帮我找"、"翻译一下"、"确认一下"、"简单说明"
```

---

### 2. 中等任务（平衡）

**特征：**
- 代码生成/修改
- 文档写作
- 简单分析
- 多步骤操作
- 需要上下文

**推荐模型：**
```
首选: ollama/qwen3.5:9b
备选: ollama/gemma4:26b
```

**触发词：**
```
"写代码"、"帮我写"、"分析一下"、"创建一个"、"修改这个"
```

---

### 3. 复杂任务（深度）

**特征：**
- 复杂架构设计
- 多文件重构
- 安全分析
- 深度调试
- 性能优化

**推荐模型：**
```
首选: minimax/M2.7
备选: ollama/deepseek-r1:32b
```

**触发词：**
```
"架构设计"、"重构"、"安全审查"、"性能优化"、"深度分析"
```

---

### 4. 推理任务（思考）

**特征：**
- 需要逐步推理
- 数学问题
- 逻辑分析
- 多方案比较
- 调试复杂问题

**推荐模型：**
```
首选: ollama/deepseek-r1:32b
备选: minimax/M2.7
```

**触发词：**
```
"为什么"、"推理一下"、"分析原因"、"解决这个bug"
```

## 使用方式

### 自动路由（推荐）

当用户不指定模型时，根据任务自动选择：

```
用户：帮我找个文件
→ 检测：简单任务
→ 自动用 qwen2.5:7b

用户：帮我写一个函数
→ 检测：中等任务
→ 自动用 qwen3.5:9b

用户：设计一个微服务架构
→ 检测：复杂任务
→ 自动用 minimax/M2.7
```

### 手动指定

```bash
/model minimax/M2.7
/model ollama/deepseek-r1:32b
```

### 模型信息

```bash
/model info
→ 显示所有可用模型及其参数
```

## 决策流程

```
任务输入
    │
    ├─ 有明确模型指定？
    │   └─ 是 → 使用指定模型
    │
    ├─ 包含推理关键词？
    │   └─ 是 → deepseek-r1:32b
    │
    ├─ 包含复杂关键词？
    │   └─ 是 → minimax/M2.7
    │
    ├─ 包含中等关键词？
    │   └─ 是 → qwen3.5:9b
    │
    └─ 默认 → qwen2.5:7b
```

---

## 成本优化原则

### 1. 能用小的不用大的
```
简单任务不用 M2.7，省钱。
```

### 2. 缓存优先
```
同一任务的结果可以复用。
```

### 3. 免费优先
```
Ollama 模型都是免费的，优先用。
```

### 4. 贵的做复杂事
```
minimax/M2.7 只留给真正需要的任务。
```

---

## 路由优先级

```
推理任务 → deepseek-r1:32b（免费+强推理）
    ↓
复杂任务 → minimax/M2.7（唯一付费，但强）
    ↓
中等任务 → qwen3.5:9b 或 gemma4:26b（免费+够用）
    ↓
简单任务 → qwen2.5:7b（免费+快速）
```

| 命令 | 效果 |
|------|------|
| `/model ollama/qwen2.5:7b` | 切换到最小的 |
| `/model ollama/qwen3.5:9b` | 切换到中等 |
| `/model ollama/deepseek-r1:32b` | 切换到深度推理 |
| `/model minimax/M2.7` | 切换到最强 |

## 实际配置

已在 openclaw.json 中配置：
```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "minimax/M2.7",
        "fallbacks": [
          "ollama/gemma4:26b",
          "ollama/qwen3.5:9b"
        ]
      }
    }
  }
}
```
